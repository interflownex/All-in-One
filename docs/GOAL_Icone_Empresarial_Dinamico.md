# GOAL — Ícone Empresarial Dinâmico (Valley / Valley Rider)

## Objetivo
Implementar sistema de personalização de ícone por empresa usando Android Shortcut API.

## Estrutura
- Moldura Valley fixa
- Logomarca da empresa variável
- Fallback seguro

## Etapas
1. Criar compositor de imagem
2. Implementar ShortcutManagerCompat
3. Criar preview UI
4. Validar backend

## Regras
- Não usar selfie
- Não alterar identidade Valley
- Somente logomarca da empresa
