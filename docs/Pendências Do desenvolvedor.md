# Pendências Do desenvolvedor

Este documento registra somente o que foi combinado como segunda etapa.

## Regra de classificação

- Tudo o que for para segunda etapa entra aqui.
- Itens ligados a valor, por enquanto, são sempre classificados como secundários.
- Cada pendência precisa deixar claro a necessidade e o impacto.

## Prioridade

Nenhuma pendência prioritária registrada neste momento.

## Modelo para novas pendências

### Título da pendência

Categoria: prioridade ou secundária.

Necessidade: o que precisa ser feito ou entregue.

Impacto: o que essa falta está impedindo, atrasando ou comprometendo.
