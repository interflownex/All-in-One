# Pacote oficial de marcas do grupo

Este diretório é a fonte de verdade dos ativos visuais autorizados do grupo.

## Ativos canônicos

| Marca | Arquivo original aprovado | Ativo canônico no repositório | Situação |
|---|---|---|---|
| All in One | `LOGO OFICIAL ALL IN ONE_2.png` | `all-in-one-logo-official.png` | Versionado e autorizado |
| Valley | `LOGO OFICIAL VALLEY_2.png` | `valley-logo-official.png` | Versionado e autorizado |
| Valley Riders | `LOGO OFICIAL VALLEY RIDERS_2.png` | `valley-riders-logo-official.png` | Binário original ainda não recuperável pelos conectores; nenhum substituto é permitido |

As referências oficiais e o estado de cada ativo estão em `config/branding/authorized_assets.json`.

## Regra inviolável

Sem autorização explícita do proprietário da marca, é permitido somente:

1. remover o fundo externo, preservando integralmente a marca;
2. redimensionar proporcionalmente.

É proibido redesenhar, recolorir, recortar, girar, distorcer, trocar tipografia, alterar linhas, curvas, formas ou composição, aplicar filtros ou substituir por símbolo alternativo.

Todos os ativos digitais devem manter fundo totalmente transparente. Nenhum agente pode criar uma versão aproximada para preencher a ausência de um original.

## Remediação automática

Ao identificar uma divergência clara, qualquer agente desenvolvedor deve corrigi-la imediatamente, executar a validação de integridade e registrar a alteração no Git. Não é necessário solicitar nova autorização para restaurar a conformidade. Esta autorização não permite criar ou modificar a arte oficial.
