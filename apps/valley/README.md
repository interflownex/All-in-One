# Valley

Shell React/Vite do consumidor Valley.

## Jornada prioritária

- Catálogo regional via API Hub.
- Checkout, agendamento, pagamento e acompanhamento.
- Saldo de Pepitas, descontos Stock e notificações.

## Contrato operacional

- Pacote: `@all-in-one/valley`.
- Fonte de API: `VITE_API_HUB_URL`.
- Evidência versionada: `config/apps/frontend_journeys.json`.
