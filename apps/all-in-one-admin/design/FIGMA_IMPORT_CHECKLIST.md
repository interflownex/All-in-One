# Checklist de criação no Figma

## Fundação

- [ ] criar novo projeto `A1 Admin — Web & Mobile — 2026`;
- [ ] importar `figma.tokens.json`;
- [ ] importar a logomarca oficial sem alteração;
- [ ] criar estilos/variables de cor, tipografia, radius, sombra, spacing e motion;
- [ ] configurar grid desktop e mobile conforme o manifesto.

## Componentes

- [ ] construir todos os componentes listados no manifesto;
- [ ] aplicar Auto Layout;
- [ ] criar propriedades booleanas, texto, troca de ícone e estado;
- [ ] criar variantes web/mobile;
- [ ] incluir foco, hover, pressed, disabled e loading;
- [ ] validar contraste WCAG AA.

## Telas

- [ ] montar todos os frames web;
- [ ] montar todos os frames mobile;
- [ ] validar quebra em 1024px e 768px;
- [ ] manter tabelas no desktop e resumo no mobile;
- [ ] criar estados loading, vazio, erro, sucesso, offline e restrito;
- [ ] marcar dados como protótipo.

## Protótipo

- [ ] fluxo de aprovação;
- [ ] fluxo de gestão de módulo;
- [ ] fluxo mobile equivalente;
- [ ] overlay da busca rápida;
- [ ] confirmação de decisão;
- [ ] navegação por teclado documentada.

## Handoff

- [ ] conferir nomes e variantes;
- [ ] publicar biblioteca;
- [ ] anexar links dos frames ao README do app;
- [ ] comparar com o shell React em desktop e mobile;
- [ ] registrar desvios intencionais.
