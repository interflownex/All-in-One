# Valley Rider

Shell React/Vite do entregador Valley.

## Jornada prioritária

- Estado online/offline do rider.
- Aceite de entregas/corridas vinculadas ao ecossistema Valley.
- Ganhos e perfil operacional.

## Contrato operacional

- Pacote: `@all-in-one/valley-rider`.
- Fonte de API: `VITE_API_HUB_URL`.
- Evidência versionada: `config/apps/frontend_journeys.json`.
