# all-in-one-business

Empresas, filiais, RBAC, recrutamento Jobs autorizado, ERP, WMS, TMS, CRM, financeiro e faturamento.

Esta aplicacao consome o API Hub com o mesmo All-in-One ID, executa acoes vivas
de aprovacao/publicacao/registro em dominios operacionais e exibe filtros,
metricas e auditoria visual das pos-acoes por status.
